# Magpie Services

Next.js website with Home, About, Services, Portfolio, Contact, Privacy Policy, and Terms & Conditions pages.

## Local preview

Run `npm install` if dependencies are missing, then `npm run dev`. Open http://localhost:3000. Use `npm run build` for the production build and `npm run start` to serve it.

## Content and settings

- Service categories and all 18 offerings come from page 4 (“What We Do”) of the supplied Canva deck. Edit `src/data/site.ts` to update the service list. The home accordion, Services page, and contact form share that data.
- The portfolio contains labeled concept studies using stock imagery.
- The contact form prepares a local text brief; it does not send enquiries.
- Theme state is shared through `ThemeProvider` and persisted in local storage. Animations respect reduced-motion preferences, and scroll reveals leave content visible when JavaScript is unavailable.

## Before launch

Copy `.env.example` to `.env.local` and replace `SITE_URL` and `CONTACT_EMAIL` with the actual public origin and business email. Both currently use reserved `.example` placeholders, as requested. Rebuild after changing them.

`/sitemap.xml` is generated by `src/app/sitemap.ts` from the public navigation and legal routes. `/robots.txt` references the sitemap. While the configured origin is a placeholder or localhost, robots are disallowed and page metadata is set to noindex. A real origin enables indexing. Canonical links use the same configured origin. The 404 route is excluded from the sitemap and carries noindex metadata.

Privacy Policy and Terms & Conditions reflect the current website features and show a review notice while the email is a placeholder. Review the business details, actual hosting practices, and legal copy before publication, particularly if enquiry delivery, analytics, or account features are added.
